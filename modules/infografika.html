Gemini Notebook (dříve NotebookLM): infografika

Vytváří vizuální shrnutí informací ve formě infografiky. Ideální pro prezentaci statistik, dat a klíčových bodů.

📚 Zdroje pro tento výstup

Při přizpůsobení tohoto výstupu můžete vybrat nebo zrušit výběr jednotlivých zdrojů. Infografika tak nemusí pracovat se všemi dokumenty v sešitu. Vyberte jen tematicky relevantní materiály a hotový výstup zkontrolujte vůči použitým zdrojům.

Příklad pro výuku: Pro infografiku o populaci pracujte jen s vybraným statistickým dokumentem a ověřte hodnoty v originálu.

💡

Tipy pro infografiky

📌

Data-driven

Prompt: "Infografika statistik z průzkumu na straně 20-25" - ideální pro vizualizaci dat.

📌

Konceptuální

"Vizualizuj hlavní myšlenky z prvních 3 dokumentů" - pro shrnutí obsahu.

📌

Porovnání

"Vytvoř infografiku porovnávající přístupy z dokumentu A vs B" - srovnávací analýza.

⚙️

Kdy použít infografiku

Ideální situace:

  • ✅ Vizualizace dat: Statistiky, průzkumy, čísla - infografika je udělá srozumitelnější
  • ✅ Shrnutí složité látky: Komplexní téma zjednodušené do vizuálního přehledu
  • ✅ Výukové materiály: Plakáty na zeď třídy, handouty pro žáky
  • ✅ Sdílení online: Infografiky fungují skvěle na sociálních sítích
  • 📽️ Prezentace: Jako slide v prezentaci pro lepší zapamatování
💎 Pro tip

NotebookLM může ve Studiu přímo vytvořit infografiku ze zvolených zdrojů, pokud je funkce pro váš účet dostupná. Před použitím zkontrolujte text, českou diakritiku, velikost písma, kontrast, množství informací, číselnou správnost i použitelnost při tisku A4.

Use Cases - Praktické příklady použití

#5

Volitelný externí postup: prompty pro obrazový nástroj

Autorský doplněk, nikoli popis nativní funkce NotebookLM

ℹ️ Co to je

Pokud potřebujete jiný styl nebo výstup externího nástroje, můžete si v chatu připravit vlastní zadání. Tento postup je oddělený od přímého vytváření infografiky ve Studiu.

🎯 Ideální pro

  • Prezentaci statistik a dat
  • Rychlé shrnutí klíčových bodů
  • Sdílení na sociálních sítích nebo prezentacích
  • Vizuální výukové materiály
📋 Hotový prompt
Vytvoř detailní Nano Banana prompt pro realistickou školní infografiku na téma [téma]. Uveď kompozici, styl, barevnost, zakázané prvky a titulky.
✨ Praktický příklad

Scénář: Potřebuješ infografiku o ekosystému lesa pro přírodovědu.

Workflow:

  1. Nahraj kapitolu o lesních ekosystémech do NotebookLM
  2. Prompt: "Vytvoř Nano Banana prompt pro realistickou školní infografiku 'Ekosystém lesa'. Kompozice: vertikální, vrstvy od půdy po korunu stromů. Styl: vzdělávací ilustrace. Barevnost: přírodní tóny. Titulky: český text."
  3. NotebookLM vytvoří detailní prompt pro AI generátor
  4. Zkopíruješ prompt do Midjourney/DALL-E a dostaneš vizuál

Diagram procesu

Pro: Vizualizaci postupů

Vytvoř AI prompt pro diagram znázorňující proces [proces] ve stylu školní nástěnky s ikonami a šipkami.
📌

Časová osa

Pro: Historické události

📋 Hotový prompt
Vytvoř prompt pro horizontální timeline [období], s klíčovými daty, ikonami a barevným kódováním.
📌

Koláčový graf

Pro: Zastoupení částí

📋 Hotový prompt
Popisnej cirkulární infografiku zobrazující poměr [data] s procenty, legendou a barevnou paletou.
📌

Mind mapa

Pro: Rozvětvené koncepty

📋 Hotový prompt
Vytvoř prompt pro myšlenkovou mapu centrovanou na [téma], s hlavními větvemi, podvětvemi a ikonami.
📌

Before/After

Pro: Srovnání změn

📋 Hotový prompt
Popisnej infografiku rozdělené na polovinu: vlevo PŘED [událost], vpravo PO [událost]. Realistický styl.
📌

Anatomický popis

Pro: Biologii, zdravovědu

📋 Hotový prompt
Vytvoř prompt pro detailní anatomický diagram [orgán/systém] s popiskami klíčových částí.
📌

Workflow diagram

Pro: Procesní plánování

📋 Hotový prompt
Napiš prompt pro workflow s kroky: START › [krok1] › [krok2] › konec. Včetně rozhodovacích bodů.
📌

Vizualizace dat

Pro: Statistiky

📋 Hotový prompt
Vytvoř prompt pro sloupcový graf zobrazující [data] napříč lety/kategoriemi. Čisté, profesionální provedení.

Geografická mapa

Pro: Zeměpis, historii

📋 Hotový prompt
Popisnej mapu regionu [region], zobrazte hranice, hlavní města, řeky a horstva s popisky.
📌

Ilustrovaný slovník

Pro: Slovní zásobu

📋 Hotový prompt
Vytvoř grid 10 slov s ilustracemi. Každé slovo má obrázek a jednoduchý popis pod ním.
